# 访谈文本主题编码工具

`sologsb-1019` 是一个面向质性研究者的本地优先主题编码工作台，使用 SolidJS、TypeScript 和 SUID 从零构建。

## 功能

- 导入带时间码或普通段落形式的访谈转写，自动切分片段。
- 创建任意层级主题树，维护操作定义、备忘录和典型示例。
- 为每个片段分别记录两位编码者的主题判断，并高亮分歧。
- 批量选择片段后重新编码，支持主题合并和按片段拆分。
- 从主题引用快速回到原文，并保留主题级与片段级研究记录。
- 完整撤销重做、操作审计、JSON 完整备份和 CSV 编码结果导出。
- J/K、数字键、Alt+A/Alt+B、搜索与通用撤销快捷键。
- 使用 IndexedDB 和 localStorage 双写保存；刷新、断网或重开浏览器后，未同步改动与未处理冲突都会继续保留。
- 多标签页字段级同步：主题的名称、层级、定义、备忘录、示例，片段的 A/B 主题判断与备忘各自是独立变更单元；不同单元自动合并，同一单元的两份不同结果都会保留，研究员在冲突中心逐项选择后才生效。导出以处理后的结果为准，存在未决冲突时暂停导出。

## 技术栈

- SolidJS 1.9
- TypeScript 5.9
- SUID Material `@suid/material`
- Vite 7
- IndexedDB / localStorage / BroadcastChannel

## 开发

```bash
npm install
npm run dev
```

开发服务器使用 Vite 默认端口，不在源码中硬编码宿主端口。

字段级合并引擎的场景测试（自动合并、双方保留、裁决、断网重连、删除冲突）：

```bash
npm run test:sync
```

## 生产构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1019 .
docker run --rm -p 10019:80 sologsb-1019
```

容器内由 nginx 监听 `80`，宿主端口 `10019` 仅由根项目端口表或部署命令映射。

## 数据说明

数据保存在浏览器本机，不会发送到远端。同步以**变更单元**为最小单位（IndexedDB v2：共享基线 + 各标签页追加式变更日志 + 裁决记录）：

- 两个标签页编辑不同单元（例如一页改主题名称、另一页改同主题定义）时自动合并，互不覆盖。
- 同一单元被两页改成不同结果时，两份结果都原样保留为待处理冲突，界面按主题/片段分组展示，研究员明确选择后该单元才生效；被搁置的结果仍记录在裁决历史中可追溯。
- 一方删除主题而另一方同期修改该主题时，删除不会单方生效，会连同编辑结果一起进入冲突处理。
- 断网期间的改动保存在本标签页的变更日志中；网络恢复、重新聚焦或每 1.5 秒定时对账时自动合并。重开浏览器会优先认领本标签页上次未同步的修订，未处理冲突不会丢失。
- 存在未处理冲突时，JSON/CSV 导出会暂停，确保导出内容始终是冲突处理后的确定结果。
